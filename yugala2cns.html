Computer Virus

[ Host-Bound Parasitic Vector ]

Attaches malicious code to benign host executables (.exe, .docx). Relies completely on human interaction, shared drives, or USB media to hop between workstations.

◈ Replication: Host Executable Insertion
◈ Propagation: Human File Transfer
◈ Speed: Moderate / User Dependent

THREAT // 02

Network Worm

[ Autonomous Self-Propagator ]

Standalone malicious program that self-replicates across computer networks. Actively probes open ports, weaponizes unpatched service bugs (SMB/RDP), and sweeps entire subnets without user aid.

◈ Replication: Autonomous Self-Cloning
◈ Propagation: Lateral Port Exploit Cascade
◈ Speed: Instant / Exponential Spread

THREAT // 03

Trojan Horse

[ Disguised Backdoor & C2 RAT ]

Masquerades as legitimate software (utilities, keygens, pdfs). Crucially does not self-replicate laterally! Delivered via phishing or downloads from an external C2 server to establish persistent backdoors.

◈ Replication: Non-Replicating (Carrier Trap)
◈ Propagation: External Web Drop / Social Eng.
◈ Speed: Stealth Ingress / Persistent C2
